# 查询结果分析

在查询结果工具栏或表格数据页点击「分析数据」，打开独立分析窗口。窗口固定打开时的数据快照；切换配置只计算本机数据，不执行额外 SQL，不自动保存结果或原始值。关闭窗口会取消计算。

首次打开时按需加载分析界面，快照在点击按钮时就固定，不会因等待期间父页面数据变化而替换。加载提示可随时关闭；迟到的加载结果不会重开窗口或启动后台计算。加载失败可重试，重试继续使用同一快照；关闭后再次打开才读取新的结果。

## 分析范围

- 查询入口：仅当前选中的语句/参数组结果。若执行结果被截断，仅统计已经返回的行。
- 表格入口：仅已加载的当前页，不包含其他页，也不包含未提交的网格编辑。
- 不将这一能力描述为全表统计或数据库服务器 profiling。需要完整数据时，可以用明确的聚合查询在服务器计算；全表分析工作流仍待实现。
- 快照不会跟随后台刷新变化，重新打开窗口才能读取新的结果。

## 列数据概况

通过列序号选择列，重复列名也可分别选择。提供行数、NULL、空文本、非 NULL 去重数、仅出现一次的值、实际类型分布、前 20 个高频非 NULL 值，以及数值的总和、平均值、中位数、最小值和最大值。

去重保持 JSON 值类型：数字 `1`、文本 `"1"`、布尔 `true` 是不同的值；NULL 不计入去重数。对象按键排序后比较内容，数组保留元素顺序。频次的分母是已加载总行数，不将前 20 项当作全部数据。

数值列默认启用「将数字文本解析为数值」，文本列默认关闭，可手动调整。数值计算不将空字符串、布尔、十六进制文本或带后缀文本转换成数字；NULL 和非数值分别计数。已经以不安全 JavaScript 整数返回的值不参与数值聚合，无法从已丢失精度的值恢复原始整数。

大整数与十进制字符串使用 BigInt 系数和十进制位数进行运算。可接受最多 256 个输入数字字符、绝对值不超过 512 的十进制指数。总和、大小比较、中位数和可终止的平均值精确保留。非终止平均值至少保留 12 个小数位，并保留输入已有的小数位数；采用远离零的四舍五入，用 `≈` 标识。驱动返回的浮点数以其已有 JavaScript 表示为输入，不声称恢复数据库原始浮点精度。

## 透视与图表

透视支持一个行维度、可选的一个列维度和一个度量列，提供行数、非 NULL 数、总和、平均值、最小值和最大值。行、列、总计均直接聚合原始行；平均值不会通过累加各组平均值得出。没有匹配行的计数是 0，数值聚合是 NULL。维度可含 NULL、空文本、重复名称和 `__proto__` 等普通文本，不会碰撞对象属性。

当前支持 20 种图表：

- 纵向柱状、堆叠柱状、横向条形、堆叠横向条形。
- 折线、面积、堆叠面积。
- 柱线组合、堆叠柱线组合。
- 瀑布、龙卷风对比、饼图、环形图、热力图、矩形树图。
- 散点、数值卡、趋势卡、KPI、仪表盘。

「图表系列」可选择行合计、单个列系列或多个系列；多系列模式可逐项勾选、全选和清空，不会为符合上限而自动舍弃系列。切换使用相同数据形态的图形类型和系列显示时复用透视结果；进入散点或数值/KPI/仪表卡时会重新投影原始行并计算，旧计算立即失效。改变目标值、仪表范围或趋势比较方式不重算数据。JSON 分析导出也记录当前图形种类和系列显示配置；配置复用使用独立的「分析配置库」，详见下文。

默认分类轴按首次出现的顺序排列，不将文本分类隐式转换成时间轴或排序；可显式选择连续数值或 UTC 时间轴，规则见下节。各系列共用数值刻度，正负堆叠分别从零累计；NULL 不绘制。普通折线/面积不跨 NULL 连线，堆叠面积还会在正/零/负符号变化处断开。组合图将最后一个所选系列绘为折线，按柱→线→点的顺序绘制，避免折线被遮挡。龙卷风图需要恰好两个非负系列，第一个向左、第二个向右。

饼图、环形图、矩形树图只接受单个非负系列，要求至少一个正值；NULL 和零不占面积，但仍保留在图例中。矩形树图当前将单层分类按权重递归切分为矩形，尚未支持多级层次维度。热力图以正/负颜色和数值强度表达，单元标签区分 NULL 与零，不将系列图例颜色误用为热度。

瀑布图要求单个且不含 NULL 的系列，按分类顺序精确累加，并添加自身的最终累计列。它累加的是每个分类已计算出的值；选择平均值等度量时，末列不能误认为透视表直接聚合原始行得到的总计。

值轴和面积比例使用百万分之一精度的有界比值近似；连续维度轴与散点坐标先精确偏移，再转为浮点比例，避免固定比值量化吞掉相近坐标。图形仍受浮点与像素分辨率限制，极近坐标可能重叠；工具提示、可访问名称和数据导出保持原精确值。图例、中英文长标签会截断显示并保留完整提示。SVG 使用明确主题颜色、独立的 800px 宽与动态高度，导出后可独立打开，不依赖应用样式。

### 散点与指标卡

散点直接选择 X/Y 源列和可选标签列，每行保持原来的坐标对应关系，不使用分组结果。原始坐标列共用界面中的「将数字文本解析为数值」开关；声明为精确十进制的计算列始终按数值参与，单轴使用计算列不会自动开启另一原始文本轴的解析。含 NULL 的行优先计入 NULL 对数，其余无法解析的坐标对计入非数值数。连续数值轴根据全部有效点的最小/最大值拟合，先精确减去最小值再换算坐标，因此范围相邻的超大整数不会在转换前丢失差异；常数轴显示在中间。

最多绘制 2,000 个点。默认启用有明确标识的固定种子水库抽样；相同输入获得相同样本，仍使用全部有效点的坐标范围。关闭抽样后，超过 2,000 个有效点会明确报错。NULL/无效数值不占抽样名额；完整分析仍受 50,000 行和预算限制。「导出绘制点 CSV」只导出实际绘制的点，包括源行序号、标签、精确坐标。JSON 另含有效对数、抽样标记、完整范围和采样配置；SVG 带抽样说明。

数值卡、KPI、仪表盘直接聚合原始行，可按列维度拆为多个卡片，不受行分类数量限制，也不会把分组平均值相加。KPI 需要输入十进制目标值并选择达到下限或不超过上限；仪表盘必须显式配置最小/最大值（默认 0/100，最小值须小于最大值）。超出范围时指针停在边界，保留实际值并显示超界说明。NULL 不画仪表指针。目标/范围无效时提供提示，不能导出误导性的 SVG。

趋势卡默认按分类首次出现顺序；显式选择连续轴后按坐标先后排序，比较末项与上一项或首项，不跳过 NULL。每个系列独立拟合数值范围，断开 NULL 处的线段。只有一个分类时，与首项比较得到差值 0；与上一项比较则没有参考值。差值保留聚合值精度，百分比为 `(末值 - 参考值) / abs(参考值) × 100`，最多六位小数，远离零四舍五入且以 `≈` 标注舍入；NULL 或零参考值不显示百分比。聚合值本身近似时会继续保留近似标记。

卡片最多 12 个可见系列，使用双列布局。长数字按卡片宽度缩放字号，中英文长标题截断并保留完整提示；仪表端点标签和主值使用独立行。

### 连续数值与 UTC 时间轴

纵向柱/堆叠柱、折线、面积/堆叠面积、柱线/堆叠柱线组合和趋势卡支持显式选择横轴：分类、连续数值、连续时间。连续轴按坐标排序、按实际差值定位，相等坐标合并后直接聚合原始行。最多 200 个分组、12 个可见系列，无隐式抽样；默认分类图仍为 60 个分类。切到饼图等仅支持分类的图形，会重新按原始分类分组；返回支持连续轴的图形会恢复所选轴设置。

数值维度显式解析十进制数字及数字文本，`1`、`"1"` 和 `"1.0"` 属于同一坐标；其解析独立于度量列的「将数字文本解析为数值」开关。保留现有的数字位数/指数限制，不接受不安全 JavaScript 整数或非数值。相邻大整数先减去精确起点，再计算位置。

时间输入格式必须明确选择：

- ISO/SQL 日期或时间戳：接受 `YYYY-MM-DD`，或日期加 `T`/空格和 `HH:mm[:ss[.fffffffff]]`。时间戳可带 `Z` 或数值偏移（`±HH`、`±HHmm`、`±HH:mm`）；统一归一化到 UTC。仅日期按 UTC 零点解释。
- 无偏移时间戳有独立选项：按 UTC 解释（默认），或者要求显式偏移；不会使用运行机器的本地时区或猜测夏令时。
- Unix 秒、毫秒、微秒、纳秒：明确指定单位，支持负值和可精确落在纳秒上的十进制输入；不会根据位数猜单位。大整数应使用驱动保真的字符串，已经丢失精度的 JavaScript 整数会被拒绝。
- 支持归一化后 Gregorian 年 0001–9999、最高纳秒精度。拒绝无效日期（例如 2 月 30 日）、24 点、闰秒、错误偏移、超范围时刻和不能精确表示的纳秒以下输入。NULL 或无效维度会使此次分析报错，不静默跳过；度量列的 NULL/非数值统计仍按原有规则处理。

时间分组提供精确时刻、秒、分钟、小时、日、周（周一开始）、月、季度、年。全部按 UTC 边界归组；时区偏移不同但表示同一时刻的输入合并。均值仍来自原始行，不能先平均各时刻再平均分桶。结果不自动插入缺失区间；已有分组缺失系列时，数值聚合仍是 NULL，折线断开。

SVG 标记 UTC、时间桶和实际间隔；JSON 保存轴、时间输入格式、无偏移策略、分桶及精确坐标（时间坐标为 Unix 纳秒字符串）；CSV 时间首列表头包含 UTC、时间桶和输入格式，行标签为归一化 UTC 时间。数值轴 CSV 也标识连续数值维度。

连续柱图按每个坐标相邻间距分配整组宽度，再拆分系列，避免高密度多系列柱组互相挤占。整组最多 48px、至少 1px，极近坐标仍可能在可用像素内重叠；此时可选择更粗时间桶、减少可见系列或使用折线图。连续趋势卡同时显示独立的值范围和时间/数值维度范围，末项取排序后的最后坐标。

目前时间轴和分桶固定 UTC；命名时区/本地日历、自动填补缺失区间、散点日期坐标、其余图表类型、聚合/窗口计算字段、实时刷新、多页仪表板、层次化图表仍待实现。不能将单个仪表图视为完整仪表板或 BI 功能。

## 逐行计算字段

点击「计算字段」可为当前固定快照添加最多 16 个公式列，选择精确十进制、文本、布尔或 UTC 时间戳输出。编辑后须点击「验证并预览」：Worker 验证全部已加载行，仅展示前 20 行；全部通过才能应用。出错显示字段、源行和公式位置，保留草稿。修改、取消和关闭会终止旧计算，旧结果不能重新启用应用按钮。

源列按一开始的顺序使用 `[1]`、`[2]` 等引用；计算列紧随源列编号，只能引用源列和前面定义的计算列，因此不存在循环或向后依赖。名称须非空、唯一且不与源列冲突。删除有依赖的字段前必须修改依赖公式；删除其他字段会重写后续引用，字符串字面量中的 `[2]` 等文字保持不变。应用后可在列概况、透视、图表维度/度量和散点中选择计算列。

例如，源列依次为 price、quantity、category：

| 字段 | 类型 | 公式 | 含义 |
| --- | --- | --- | --- |
| Revenue | 精确十进制 | `[1] * [2]` | 逐行金额 |
| Profit | 精确十进制 | `[4] - 1` | 引用上一计算列 |
| Safe ratio | 精确十进制 | `[1] / NULLIF([2], 0)` | 分母为零时得到 NULL |
| Rounded ratio | 精确十进制 | `DIVIDE([1], [2], 6)` | 显式选择六位小数 |
| Caption | 文本 | `CONCAT([3], ': ', TEXT([4]))` | 显式数值转文本 |
| Month | UTC 时间戳 | `DATE_TRUNC('month', '2026-11-06')` | UTC 月起点 |

支持四则运算、取余、比较、AND/OR/NOT，以及 IF、COALESCE、IFNULL、NULLIF、ISNULL。布尔条件必须为 TRUE/FALSE/NULL；NULL 按三值逻辑传播，IF 与 COALESCE 只计算实际选择的分支。单引号文本使用两个单引号转义，例如 `'it''s'`。这是一套白名单公式语法，不执行 JavaScript 或 SQL。

数值函数包括 NUMBER、TEXT、ABS、ROUND、FLOOR、CEIL、TRUNC、DIVIDE、MIN、MAX。使用精确十进制计算，范围沿用结果分析的 256 个数字字符和 ±512 指数限制。`/` 只接受可精确终止的小数，`1/3` 会报错；应改用 `DIVIDE(1,3,12)` 显式舍入。DIVIDE 支持 0–128 位小数；ROUND 支持 -128–128 位，均按半值远离零处理。预览和分析显示发生显式舍入的行数，后续计算使用舍入后的值。MIN/MAX 仅比较当前行的多个参数，尚不是聚合或窗口函数。

文本函数包括 CONCAT、LOWER、UPPER、TRIM、LENGTH、SUBSTRING、REPLACE、CONTAINS、STARTSWITH、ENDSWITH；文本操作须使用文本输入，可通过 TEXT 显式转换。SUBSTRING 从 1 开始，长度和截取按 Unicode 码点处理。

时间函数包括 DATE、YEAR/MONTH/DAY/HOUR/MINUTE/SECOND、WEEKDAY、DATEADD、DATEDIFF、DATE_TRUNC。只使用 UTC，保留最高纳秒精度，日期范围为 0001–9999 年；无偏移输入按 UTC 解释。WEEKDAY 为周一 1 至周日 7；DATEADD 的单位限 day/hour/minute/second；DATEDIFF 返回完整单位差，向零截断。非法日期、零除、输出类型不匹配或溢出均中止本次计算，不静默丢弃行。

每个公式最多 4,096 个 UTF-16 单元、512 个 AST 节点、32 层解析嵌套；输入或生成文本最多 8,192 个 UTF-16 单元。一次计算最多 20,000,000 次节点求值，并继续受 50,000 行及输入/输出各 32 MiB 投影预算限制。主线程只预检和传递所需的源列，每 256 行让出执行；预览在 Worker 中验证全部行，不向主线程返回全部派生数据。

分析配置库使用版本 2 保存公式、输出类型及必要源列绑定；不含计算字段的旧版配置保持版本 1。加载时先映射公式输入并重写数字引用，公式输出名称可在映射窗口中修改，解决目标源列重名。配置包含用户手写的公式常量，请在分享前核对；不保存 SQL、源行或计算结果。加载旧版配置会清除当前计算字段。分析 JSON 导出另含公式定义和舍入统计。

此能力目前是固定快照的逐行派生列；跨行聚合/窗口公式、服务端计算、实时刷新和完整仪表板仍待实现。

## 资源与导出

- 最多 50,000 行、32 MiB 选中值估算预算、32 层嵌套。
- 在结构化克隆数据给 Worker 之前逐项检查投影列；每 256 行让出主线程，切换/关闭会取消旧预检。Worker 再次独立校验预算。
- 透视最多 200 个行组、40 个列组。超限明确报错，不返回隐式截断或抽样的统计。
- 默认分类图和分类趋势卡最多 60 个分类，连续轴最多 200 个分组，均最多 12 个可见系列；数值/KPI/仪表卡从原始行聚合，散点遵循上述独立点数限制；超限时保留完整透视和数据导出，提示缩小分组或选择系列，不静默丢弃尾部。不满足某图形的数据语义时显示原因并禁用 SVG 导出。

- CSV 对可能被表格软件解释为公式的维度/表头文本添加单引号。统计数字以文本写入文件；表格软件仍可能自动推断数值类型，精确数据交换优先使用 JSON。JSON 中数值统计使用字符串及独立 rounded 标记。

## 分析配置库

「分析配置库」支持本机命名保存、搜索、加载、覆盖、重命名和删除；可跨查询结果或表格当前页复用。保存模式、图形、活动字段绑定、聚合、数值文本解析、连续轴/UTC 分桶、抽样及 KPI/仪表/趋势设置。不会保存来源标题、SQL、源行或统计结果，也不会因加载执行查询。

默认不保存特定系列的源值；单系列/手选系列的配置加载后需重新勾选。勾选「同时保存所选系列值」后才按稳定键保存值和顺序。合计与全选可直接复用，全选也包含新结果中新出现的系列。已保存系列若在新结果中缺失，会暂停绘图和 SVG 导出，直到用户重新选择；不会悄悄回退到合计或只显示剩余系列。

加载和导入均先核对字段映射。只有名称相同、类型相同（忽略大小写与首尾空白）且名称唯一的目标列才会自动匹配；重名、缺失和类型变化必须手动选择。旧列序号仅作提示。确认后一次应用到当前固定快照，旧计算结果立即失效。

「导出当前配置」生成独立配置 JSON；「导入配置 JSON」只接收此结构，不接收带结果数据的分析 JSON。导入不会自动存入配置库；应用后可另存。配置文件上限 64 KiB，配置库最多 100 项，单个系列键最多 2,048 个 UTF-16 单元、最多 12 个键。导出特定系列值同样需要显式勾选。

配置库写入应用数据目录的 `analysis-presets.json`，不使用浏览器 localStorage。列表只返回名称、模式、图形与是否含系列值，不返回值。原子替换、revision 检查和稳定锁文件防止并发覆盖；每次操作在锁内重读磁盘，锁竞争最多等待 500ms 后提示刷新重试。损坏文件原样保留，不能通过再次保存静默覆盖。参数预设也复用这套存储机制。这是本机配置复用，尚不包含团队共享、实时数据源或仪表板布局。
