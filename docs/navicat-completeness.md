# Navicat 能力补齐与界面验收

更新：2026-11-07。开发分支：`feature/navicat-completeness`，发布基线：`v0.2.1` / `37909a2`。

本轮已完成批次收录于 `v0.3.0`，以下各批“未提交/未发布”描述保留当时状态；当前交付状态以仓库提交、版本标签及 Release 为准。完整能力补齐目标仍未完成，后续功能开发保持暂停。

目标保持为完整补齐功能差距、检查并改善现代桌面界面、修复布局错乱与代码质量/性能问题。下表包含尚未实现的工作；历史审计中的“范围外”不是本轮排除项。本文件不宣称已达到完整替代能力。

对照来源：[Navicat Premium 官方功能矩阵](https://www.navicat.com/en/products/navicat-premium-feature-matrix)，2026-11-06 读取。按本项目的模块与验收方式重组，避免将“有入口”“支持某个兼容协议”当作完整功能或兼容性保证。旧实现与实库记录见 [历史审计](navicat-gap-audit.md)。

状态约定：**已有基础**表示已有实现但仍需逐项覆盖差距；**本轮实现**表示工作区已实现，尚未发布；**待实现**表示没有满足该项的完整实现；**待验收**表示缺少对应平台或环境的实际证据。
