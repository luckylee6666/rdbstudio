# 命名参数查询

在 SQL 中使用 `:name`，点击运行后输入值。名称使用 ASCII 字母或下划线开头，后续可包含数字；同名参数可以重复引用。SQLite、PostgreSQL、MySQL 使用驱动原生绑定，参数值不会被拼接成 SQL 字面量。Redis 不使用这个 SQL 参数窗口。

```sql
SELECT * FROM orders
WHERE customer_id = :customer_id AND total >= :minimum_total;
```

支持文本、64 位有符号整数、小数、浮点数、布尔值、日期、日期时间、JSON、十六进制二进制，以及每一种类型的 SQL NULL。空文本与 NULL 分别处理。整数和小数在输入与传输时保留为字符串，避免 JavaScript Number 提前舍入；SQLite 的 NUMERIC 运算仍受 SQLite 自身精度限制，MySQL 小数最多 65 位有效精度、30 位小数。

日期使用 `YYYY-MM-DD`，日期时间使用 `YYYY-MM-DD HH:mm:ss` 或 `T` 分隔，可带小数秒，不附带时区。二进制使用成对十六进制字符，可加 `0x` 前缀。窗口会提前检查日期合法性、类型格式、有限浮点值及大小限制；后端再次校验。

类型会随查询标签页保存；值默认只保留在当前组件会话。勾选“保存默认值”才将值写入本机工作区。取消勾选后再次确认执行会移除旧默认值。关闭窗口不会修改默认值。历史只保存 SQL 模板；参数化查询失败时历史使用通用错误，避免保存驱动可能回显的参数值。显式默认值并非凭据保险箱，不宜用来保存真实密码或令牌。

多语句执行沿用查询标签页的独立数据库会话、事务和取消机制。参数类型和值会在执行前统一校验，缺少参数时不会先执行前面的写入。SQL 或目标连接发生变化时，旧参数窗口关闭，需重新运行。连接重建后，后端拒绝使用旧连接代次确认的参数请求。

字符串和普通注释中的 `:name` 不作为参数；MySQL 可执行注释按连接实际版本判断是否生效，有效注释中的参数参与原生绑定，版本不满足或不属于当前服务端的注释不要求参数。只读连接拒绝可执行注释，避免隐藏的输出或事务控制绕过保护。PostgreSQL 的 `::type` 转换、E 字符串、dollar quote、MySQL 的会话字符串模式均有专门处理。不能在同一语句中混用命名参数和原生位置参数。脚本后续语句可能通过 SET、存储函数或事务回滚改变字符串规则，因此预检保守收集可能出现的参数名，执行每条语句前再读取实际模式。歧义脚本可能多显示一个实际模式下未使用的参数；远端数据库会额外查询会话模式。这些行为用于避免漏绑及错误替换。

可视化 EXPLAIN / PostgreSQL EXPLAIN ANALYZE 同样支持参数窗口，显示实际绑定后的计划。普通连接上的计划引用来源查询的同一物理会话，可以读取临时对象和未提交数据；写入型 Analyze 的改动仍属于来源事务。只读连接沿用原生只读保护的独立执行路径，工具栏会注明，不承诺继承来源会话状态。

切换标签页不会取消计划或重跑 Analyze，结果仅保存在运行时内存中。重启恢复的 Analyze 标签不会自动执行；旧会话身份不会持久化，须从来源查询重新生成计划。非只读 Analyze 每次手动重跑都需确认。源查询关闭、重置或连接重建后，旧计划不能绑定替代会话。

关闭已完成的计划不会关闭或回滚来源查询。关闭正在执行的计划会先确认：取消沿用查询执行的安全策略，丢弃可能处于未知状态的共享连接；来源查询会需要重置，未提交事务可能回滚。

限制：每个脚本至多 128 个不同参数，单条语句至多 1024 次引用；单值 1 MiB，总值 8 MiB；同一语句重复引用展开后的绑定值也限制为 8 MiB，避免重复大值放大内存与网络开销。批量参数表格及文件输入见下节；命名参数集可显式保存并跨标签页加载，见下节。编辑器现在向后端传递原始 SQL，由同一个物理会话按实际方言和每条语句执行前的模式递进分句。支持 SQLite 触发器、PostgreSQL 嵌套注释/Unicode dollar quote/SQL BEGIN ATOMIC 函数体、MySQL `DELIMITER` 存储过程脚本；DELIMITER 仅在本地解析，不发送给服务器。原始脚本限制 8 MiB、128 条语句，模式歧义分析有状态数和扫描工作量上限，超限时在执行前提示拆分。

自动事务包装由后端决定：脚本显式使用 BEGIN/COMMIT/ROLLBACK/SAVEPOINT 或设置 autocommit/transaction 时保留其自身事务控制；已有事务内运行脚本不会自动提交来源事务。失败时区分完整回滚、部分提交和自行管理事务，MySQL DDL 等隐式提交不能承诺撤销。PostgreSQL 用户事务报错后仍可执行 ROLLBACK 恢复。取消丢弃当前连接并要求重置；结果的行数和字节预算按整份脚本共享。

## 批量参数集

参数窗口切换到“批量参数集”后，每行是一组值，列类型对全部行生效。支持添加、复制末组、删除及每页 10 行编辑，最多 100 组。SQL NULL 单独勾选，与空文本区分。切换批量模式会重新检查后续组可能遇到的会话字符串模式，必要时补充参数列。

展开“导入或粘贴参数值”可选择 CSV、TSV、JSON 文件或粘贴内容，再点击替换按钮导入。CSV/TSV 第一行为参数名，列可调换顺序，但不能缺少或重复；未加引号的 `\N` 为 NULL，加引号的 `"\N"` 为字面文本，空字段为空文本。JSON 为对象数组，值只接受字符串或 `null`；数字和布尔值也需使用字符串，以保留 64 位整数及小数精度。导入不会修改已选列类型。复制/导出 JSON 仅导出值，重新导入时需确认列类型。

批量草稿只保留在当前编辑器组件内存中，不写入工作区默认值或历史；切换 SQL/目标不会自动复用其他查询的草稿，组件卸载或应用重启后草稿不保留。主动复制/导出可将值写到剪贴板或所选文件；也可在命名参数集窗口明确勾选保存值，将其保存在本机资料库。

整个批次持有同一个会话锁，所有组在第一条 SQL 执行前完成类型、缺参、重复绑定大小及方言预检。后续组的首条语句也考虑前一组改变字符串模式的情况。默认在会话和脚本允许时用一个事务包装全部组；已有事务、显式事务控制和 MySQL 手动提交模式保持有效。取消会中止执行、丢弃连接，随后需重置会话。

遇到第一个失败即停止，显示组号、组内语句号、此前完成组数和回滚状态；事务提交失败单独提示，不编造失败语句。完整回滚表示整批改动已撤销；MySQL DDL 的隐式提交可能造成部分改动保留；关闭包装或脚本自行管理事务时不承诺自动回滚。成功后用组选择器查看每组结果，只渲染当前组的结果标签。

批次限制：SQL 字节数乘组数不超过 32 MiB，全部参数值合计 8 MiB，各值/绑定原有上限继续生效；所有组共用方言分析工作预算。结果行数和行数据字节预算在整个批次共享（10,000 行、8 MiB），超出部分标记截断。

## 命名参数集与跨标签页复用

在参数窗口展开“已保存的参数集”，可以搜索、加载、另存、覆盖、重命名和删除。资料库按数据库类型区分，在本机各查询标签页间共享；加载要求参数名集合完全匹配，顺序可以不同。单组参数集也可用于执行计划；批量参数集仅用于 SQL 编辑器。加载只替换窗口输入，不执行 SQL，不自动选择保存默认值。批量加载会重新检查当前连接的未来模式参数名，目标代次失效或参数不匹配时保留原输入。

保存窗口默认只保留参数名、类型、单组/批量模式和事务包装选项。明确勾选“将当前值保存在本机文件中（未加密）”后，才保存全部行的值及 NULL。加载仅类型的参数集会清空当前值，布尔值使用 TRUE 起始值；整数、日期等仍需填写合法值才能运行。覆盖时未勾选保存值，会移除原参数集保存的值。重命名保持内容，删除不会清空已经加载到其他查询窗口的输入。

预设保存在应用数据目录的 `parameter-presets.json`，不依赖浏览器 localStorage 配额。列表只返回元数据，主动加载才返回值；资料库最多 100 项、序列化文件最多 32 MiB，每个参数集继续遵循参数数、类型及整批 8 MiB 值上限。文件读写及校验在后台完成；写入先生成私有临时文件、同步后原子替换，成功后才更新内存。读取损坏或不支持版本的文件会报错并保留原文件，不静默清空。

同一个应用实例中的管理操作共用锁，并通过 revision 检测不同标签页的旧版本覆盖、重命名或删除；冲突时需刷新后重新选择。此机制不是多进程共享同一资料目录的文件锁，也不是团队同步服务。
