# 离线关系模型

从左侧「模型」打开「离线模型」。无需连接数据库即可新建 SQLite、PostgreSQL 或 MySQL 方言的模型；已应用的编辑保存到本机资料库。模型编辑不会连接数据库或执行 SQL。

## 编辑与保存

- 新建模型后添加表，编辑表名、Schema、注释，以及字段名、类型、主键、允许空值、唯一标记和注释。字段可以上下移动；主键字段自动禁用允许空值。
- 在表编辑器「键与约束」中独立调整主键字段顺序，添加、命名、重排或删除复合唯一约束。重排字段显示顺序不会改变已经确定的主键顺序；删除仍被唯一约束引用的字段会被拒绝，需先调整约束。
- 添加关系时选择引用表与被引用表，并按顺序选择字段映射。支持复合关系、自引用、一对一/一对多及标识关系；可选择更新/删除动作 NO ACTION、RESTRICT、CASCADE、SET NULL、SET DEFAULT。引用使用稳定内部 ID；表或字段改名、字段重排不会改变关系目标。
- 通过画布选择、双击表，或使用上方表/关系下拉框打开编辑器。卡片最多显示前 12 个字段，并显示剩余数量；完整字段在编辑器内查看。
- 「应用并保存」成功后才替换当前模型并记录历史。可撤销和重做编辑、关系变化、删除表、位置移动与排列；撤销/重做也会保存到资料库。
- 拖动结束保存表的位置。「排列各表」会按每行最高卡片和自引用弧线空间重新排列并适配画布。多个自引用关系分别绘制，标签保留在卡片上方。
- 删除仍被关系引用的字段会被拒绝；删除表会明确提示同时删除它的关系，确认后可以撤销。

撤销历史只在当前模型编辑会话内保留，每个方向最多 50 个快照且受约 16 MiB 序列化估算预算限制。关闭标签、重启、切换模型、重载、复制或重命名会清空历史。切换到其他工作区标签再返回不会清空正在编辑的表单或历史。

## 资料库和文件

资料库支持搜索、另存为新模型、重命名、删除和重新加载。删除整个模型不可撤销，需要保留时先导出。JSON 导入经过版本、大小和结构校验，再由用户命名并确认保存；导出使用原生保存对话框。

文件格式为 `rdbstudio-model`，包含名称与版本 1 或 2 模型，不保存连接配置、SQL 或源数据。新建模型使用版本 2；旧版本继续按原字段顺序解释主键，应用表或关系编辑时升级到版本 2；撤销可恢复旧版本快照。版本 2 新增可选的有序 `primaryKey`、命名 `uniqueKeys` 以及关系 `onUpdate`/`onDelete`，旧程序不能读取新版本。只接受项目支持的字段；外部模型格式、未知字段、重复 ID/名称、缺失关系目标和非法坐标均会被拒绝。类型和关系基数目前仅是设计元数据，不代表对应数据库的约束已经有效。

本机资料库存储在应用数据目录的 `offline-models.json`，与查询参数集、分析配置分别保存。写入使用文件锁、版本冲突检查和原子替换；损坏文件不会被新建空文件覆盖。模型已被其他窗口/进程修改时，旧版本编辑不会覆盖新版本，编辑窗口会保留草稿并显示冲突。关闭编辑窗口后可重新加载最新文档，或另存当前已加载文档的副本；另存副本不包含尚未应用的表单草稿。

| 范围 | 上限 |
| --- | --- |
| 本机资料库 | 100 个模型、总计 32 MiB |
| 单模型/导入导出文件 | 2 MiB；导出文件含格式和名称，因此边界模型可能需要缩减后才能导出 |
| 每模型 | 200 张表、总计 4,096 个字段、1,000 条关系 |
| 单表 | 256 个字段 |
| 单关系 | 16 对字段映射 |
| 命名唯一约束 | 每表 64 个、每模型 1000 个，每个最多 256 个不重复字段 |

## 生成建表 SQL

保存模型后点击「生成 SQL」，即可预览当前已保存版本对应的 SQLite、PostgreSQL 或 MySQL 建表脚本。未应用的表单草稿不参与生成。可以复制、通过原生文件窗口导出 `.sql`，或选择同方言、已连接且可写的连接，打开带固定 SQL 快照的新查询标签。预览、导出和交接均不执行 SQL；在查询编辑器中检查后显式运行。

脚本包含字段、独立顺序的主键、单列唯一标记、命名复合唯一约束及模型关系和外键动作。一对一关系会为引用端字段组合添加唯一约束；标识关系要求引用字段均属于子表主键。外键目标必须是完整主键或唯一键（包括其他一对一关系产生的唯一键），字段映射保持原顺序。MySQL 在引用复合键顺序不同时补充同字段集合的有序唯一键。PostgreSQL/MySQL 先创建所有表，再添加外键，因此支持循环引用；SQLite 在建表语句中声明外键。PostgreSQL 为键约束分配避开模型中对象名称的名称。

- 默认命名空间：PostgreSQL `public`、SQLite `main`；MySQL 使用当前数据库。PostgreSQL/MySQL 可显式勾选创建所需 Schema/数据库；目标同名表已存在时仍由服务器报错，不静默跳过、不删除或迁移原表。
- SQLite 类型作为完整标识符引用，支持任意声明类型名称；注释只写入 SQL 注释，不作为数据库元数据保存。脚本开头的 `PRAGMA foreign_keys = ON` 必须在事务外运行才会生效。附加数据库必须已挂载，不支持跨数据库外键。
- PostgreSQL 支持常用内置类型、字符/位串长度、数值精度、时间精度、最多六维数组，以及带可选 Schema 的自定义类型/域名称。自定义类型须已存在；负 scale 或 scale 大于 precision 需要 PostgreSQL 15+。SERIAL 不能声明为可空或数组。
- MySQL 支持常用内置类型、整数显示宽度、UNSIGNED/ZEROFILL、字符/二进制长度、DECIMAL、ENUM/SET；生成表使用 InnoDB、utf8mb4 与 utf8mb4_bin。ENUM/SET 使用单引号加倍转义。因无法预知会话 SQL mode，枚举值与注释含反斜杠时拒绝生成，需要先移除，再在编辑器按目标会话规则调整。
- 名称长度、重复对象/约束名、主外键关系及支持的类型语法会提前检查；不支持的类型片段会阻止整份脚本生成。服务器版本、权限、自定义类型、键长、行长和最终类型兼容性仍由目标服务器确认，预览会列出需要核对的事项。MySQL DDL 可能隐式提交。

SET NULL 要求所有引用字段允许空值，否则拒绝生成。MySQL InnoDB 不支持 SET DEFAULT，因此生成时拒绝；SQLite/PostgreSQL 会提示当前模型没有字段默认值，需要核对引擎隐式默认值与外键约束。命名唯一约束参与外键候选键检查，PostgreSQL 同 Schema 下的约束索引名冲突会提前拒绝。

生成脚本最大 4 MiB。当前模型 v2 没有默认值、CHECK、独立索引、生成列或自增策略字段；不能用本流程替代完整物理结构迁移。SQL 文件反向工程、完整物理结构反向工程与模型差异同步仍待实现。

## 从数据库导入

点击「从数据库导入」，选择已连接的 SQLite、PostgreSQL 或 MySQL 来源，可使用只读连接。选择 Schema/数据库、筛选并勾选表后，点击「读取并预览」；跨 Schema 的选择会保留，可单独移除。最多选择 200 张表，列表只显示前 500 张匹配表，超出时需缩小筛选范围。

预览保留当前 v2 模型能表达的字段名称/类型/可空性、字段及表注释（来源支持时）、实际顺序的主键、普通唯一键，以及已选表之间的外键映射与更新/删除动作。主键顺序不依赖字段显示顺序。SQLite 未声明目标字段的外键按所选父表主键解析；指向未选表的外键不导入并给出提示。源字段类型仍需经过前向 SQL 生成器检查，成功导入不保证能生成或运行完整重建脚本。

必须核对遗漏与差异、勾选确认并命名后，才能另存为本机新模型。读取和预览不自动保存、不执行生成 SQL，也不读取源数据行或修改源结构；保存失败保留预览及名称。改变来源或选择范围会清除旧预览和确认；关闭读取窗口会丢弃迟到结果，隐藏模型标签则保留草稿。

- 不保留默认值、CHECK、生成表达式、自增/标识策略、普通索引、表达式/部分/前缀索引、索引选项、权限、触发器及完整表选项。生成列作为普通字段导入。唯一键只保留受支持的普通列组合；SQLite 非 BINARY 排序规则、PG 非默认操作符类和 NULLS NOT DISTINCT 等特殊唯一语义不会被当成普通唯一键。
- 外键的延迟、验证、MATCH、限定字段动作等选项不保留；名称冲突时会重命名并提示。源主键字段实际允许 NULL 时，模型会收紧为非空并提示。SQLite 原约束名、排序规则与建表细节不能由 PRAGMA 完整恢复，均有覆盖范围提示。
- SQLite 只支持 `main`；读取在同一事务中进行。PostgreSQL 使用同一只读、可重复读事务。MySQL 读取前后比较每张表的建表定义，已知变化会拒绝，但不能保证跨表 DDL 快照；导入期间应避免并发结构修改。
- 原生端最多同时读取两个预览，每次限时 60 秒。除模型本身限制外，原始结构累计限制为 2 MiB/4096 字段；超限或任一表不可读时整批失败，不静默截断模型。差异提示最多显示 1000 项，其余以数量提示。

这是带明确遗漏报告的关系结构导入，不能代替完整备份、无损物理反向工程或迁移工具。SQL 文件导入、模型比较和双向同步仍待实现。

## 当前边界

这是离线关系模型编辑基础。概念/逻辑/混合模型、维度/Data Vault、命名词典、批量结构编辑、SQL 文件及完整物理结构反向工程、模型比较/同步、打印和模型图形导出仍待实现。同端点关系使用不同曲线和标签位置；复杂图形的手动路由与自动避障仍待完善。

前端测试、原生文件读写与独立 Chrome 的真实桥接交互已有验证；浏览器结果不替代 Tauri/WKWebView 或 Windows 实机验收。
